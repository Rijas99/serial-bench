About the helper

Portable for Windows 10/11, 64-bit. No installation or administrator access needed. Each laptop runs its own helper. Close its window to stop it.

The helper opens a private pairing link. If your default browser is not Chrome or Edge, copy that link from the helper window into one of them.

The download is unsigned. Windows may show a security prompt. Only run a copy you trust from this project’s GitHub release.

No reply or helper blocked?

A device can be online and still block ICMP ping. Check the IP address, laptop network, device power, firewall, and Wi-Fi client isolation.

If the helper is running but cannot connect, use Check helper again and allow local network or loopback access in this site’s browser permissions. A company browser policy may block access.

Ping runs on this laptop through the Windows helper. Device addresses and results are not sent to a remote server.
