What setup does
Installs for your Windows account without administrator access. Start with Windows is enabled by default; you can change it in Setup. The helper runs near the Windows clock.
A webpage cannot silently install a program. Run Setup once and approve browser or Windows prompts. This approved website connects automatically, including in a new browser or when saved site data has been cleared.
Use the tray icon to open the tester, stop the helper, or disable auto-start. Uninstall from Windows Settings → Apps.
The download is unsigned. Only run a copy you trust from this project’s GitHub release.

          
No reply or helper blocked?
A device can be online and still block ICMP ping. Check the IP address, laptop network, device power, firewall, and Wi-Fi client isolation.
If the helper is running but cannot connect, use Check helper again and allow local network or loopback access in this site’s browser permissions. A company browser policy may block access.
